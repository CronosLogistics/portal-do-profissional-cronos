## Server integration rules (src/lib)
- Daily Entra sync lives in `src/lib/entra-sync.server.ts` (pure rules in `entra-sync.rules.ts`), triggered by the managed schedule calling `/api/public/jobs/entra-sync` or an admin's `syncNow`; it matches by `entra_oid` (email only before linking), mirrors name/email/employee ID/accountEnabled, bans disabled accounts, and records the run (origin, who triggered it) in the singleton `status_sincronizacao`, guarded by a 10-minute `reservar_sincronizacao` lock. Why: Microsoft is the source of truth for professionals.
- Monthly praise compilation (D2): Power Automate POSTs `{mes_ano, html}` to `/api/public/compilado-elogios` with `X-Webhook-Secret` (secret `COMPILADO_WEBHOOK_SECRET`); `receber_compilado` (service_role only) stores the raw HTML in `compilados_elogios` (outside `avisos.mensagem`, so the sanitizer can't break it) and upserts one `tipo='compilado'` aviso per month; slide 4 reads `compilado_vigente()` (1 month) and the reader shows the HTML in a script-less sandboxed iframe. Why: keep the email's full layout safely.
- Praise (D1) reads SharePoint RQ0013 server-side only (`src/lib/feedback.server.ts`, 5-min cache), resolves AuthorLookupId through the site's User Information List with createdBy identity fallback, and filters in `feedback.rules.ts` by the caller's profile email: involved rows or rows where they are the GESTOR_CONSIDERACOES person; only `field_4 = 'Elogio - EL'`. Why: the browser never gets the token or other people's rows, and the author and manager come from SharePoint.
- OfficeContext resolves the caller's verified profile email through projected SharePoint corporate-person lookup and active status server-side, never localStorage. Why: display only the professional's actual office.
- Pendências read SharePoint server-side (`pendencias.server.ts`/`.rules.ts`), filter by caller's profile email as Responsável (Plano de ação also as Gestor responsável), recompute days/status per request (HOJE() columns are stale); admin-only until v2. Why: no token or others' rows reach the browser.
